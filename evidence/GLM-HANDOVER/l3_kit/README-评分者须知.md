# L3 成对盲评 · 评分者操作说明

> 目标：回答"剪得好不好"——客观指标（L1）测不了的部分。
> 协议：Chatbot Arena 式成对盲评（匿名 A/B、随机顺序、允许平局）。
> 量表：VlogReward 五维裁剪版。

## 你要做的事（约 30-40 分钟）

1. 打开本目录，逐对播放 `pairXX_A_*.mp4` 和 `pairXX_B_*.mp4`
   （同一素材的两个剪辑版本，来源已匿名——你不知道哪个是谁剪的）
2. 打开 `评分表.csv`，每对填：
   - 五维各 1-5 分（A、B 各一列）：**意图达成 / 叙事连贯 / 节奏 / 镜头选择与切点自然度 / 技术质量**
     - 1=很差 2=较差 3=一般 4=良好 5=优秀
   - **总体偏好**：A / B / 平（这是主指标，五维只做归因）
   - 一句话理由（可选但强烈建议——归因到具体镜头）
3. 全部填完把 `评分表.csv` 交给 GLM 汇总

## 评分参考锚点

| 分 | 节奏维度示例 | 镜头选择示例 |
|---|---|---|
| 5 | 张弛恰如意图 | 每个镜头都有存在的理由 |
| 3 | 个别段落拖/赶 | 大体合理但有无意义镜头 |
| 1 | 明显拖沓或赶戏 | 有明显无关/重复/错误镜头 |

## 保密

`答案表_评分者勿看.csv` 是 A/B 对应关系的答案（主控汇总用）——
**评分期间不要打开**，否则盲评失效。

## 当前覆盖

## 统计口径（GLM 汇总时执行）

- 总体偏好：配对 sign test + 胜率（>60% 且置信区间不含 50% 才判真差异）
- 五维：报均值与 Fleiss' kappa（<0.4 说明量表需修订，先改表再续评）
